# Aegis AI — وثائق النظام ومعمارية الوكلاء

مرحباً بك في وثائق مشروع **Aegis AI**.

تم إعداد دليل تفصيلي شامل يغطي كل تفصيلة في النظام:
- معمارية النظام الموزع ومبدأ الـ Autonomous AI-SRE.
- دورة حياة الحادث الكاملة من الاكتشاف إلى الحل.
- طبقة نماذج الذكاء الاصطناعي (`apps/agents/llm/`) ودعم Ollama (Llama 3.2) المحلي المجاني و OpenAI.
- محرك حلقة التفكير والتنفيذ ReAct في كلاس `BaseAgent`.
- سجل الأدوات المركزي (`ToolRegistry`) ومبدأ الصلاحيات الأقل.
- شرح دقيق للوكلاء الخمسة المتخصصين:
  1. `TriageAgent`: الفرز وتحديد الأولوية والخطورة.
  2. `DiagnosisAgent`: التحقيق واكتشاف السبب الجذري بالأدلة.
  3. `RemediationAgent`: تخطيط الإصلاح وإدارة المخاطر والموافقة البشرية.
  4. `VerificationAgent`: التحقق بعد المعالجة وحلقة التعافي المغلقة.
  5. `PostmortemAgent`: كتابة التقرير الشامل الخالي من اللوم.
- أوركسترا سير العمل المتين عبر Temporal (`IncidentResolutionWorkflow` و `activities.py`).
- سيناريو الاختبار والمحاكاة الشامل `test_agent_e2e.py`.
